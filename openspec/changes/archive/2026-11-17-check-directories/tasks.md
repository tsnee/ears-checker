# Tasks

All work is on branch `batch-check-other-projects`, the "Check other projects" theme (roadmap item 10); its draft PR is opened when the first commit is pushed. The owner pushes from their own shell; Claude reads runs with `gh`. Test-first: each behavior's test is written and seen failing before the code that makes it pass. Editing, deleting, skipping, or loosening an existing test is asked of the owner first, with the requirement it covers. After each task, every changed file is scanned for raw control, format, and separator characters by general category.
